## Overview

In today’s data-driven world, modern finance demands innovative solutions. This project focuses on:
- Stock prediction models
- Portfolio optimization
- Risk management
- Time-series forecasting

It leverages powerful Python libraries such as pandas, scikit-learn, and matplotlib.
